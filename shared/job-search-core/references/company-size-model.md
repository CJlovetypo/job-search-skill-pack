# 客观规模与求职解释

用户选择：以客观规模为依据，结合求职视角。首版把“大厂／中厂／小厂”明确限定为**雇主组织规模**，不评价品牌名气、薪酬、稳定性或个人匹配。

研究依据：国家统计局按行业结合人数、营业收入或资产划型，不能把所有行业都按一个法定人数线归类，也不能将“统计大型企业”直接称为求职语境的大厂。[统计划型说明](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903367.html)。招聘平台会另外保存雇员人数区间；LinkedIn 官方字段定义包括 201–500、501–1000、1001–5000、5001–10000 等区间。[官方公司字段说明](https://learn.microsoft.com/en-us/linkedin/shared/references/fields/company-profile)。

本产品在这些规模事实之上采用可解释的内部简化模型：员工不少于 5,000 人为大厂，500–4,999 人为中厂，少于 500 人为小厂。这是便于理解组织体量的产品阈值，**不是上述机构发布的“大厂”认定标准**。营业收入、资产、行业特点保留为公司背景；当前缺少同口径收入资料时不混用估值或融资额替代收入，更不通过知名度给人数不足的企业升级。

适用与证据：

- 仅已核实性质为私企／外企的主体适用；国企等不适用，性质未知则待核实。
- 优先经核实的年报、官网、官方招聘介绍；保留原始人数、统计主体、日期、证据 URL。LinkedIn 成员数、关注人数、平台商户、代理人或参保人数不自动当作员工总数。
- 集团和招聘实体严格区分，集团口径会随标签展示；明确分支或子公司只有集团数据时不直接套用。
- 明确人数区间完全落在同一档才赋值；“至少 600 人”没有上界，不能凭其确定中厂。约数使用 20% 容差检查是否跨档；跨档待核实。
- 超过两年的资料只保留历史，不据此确认当前标签；无统计日期时标为待核实，不能当成最新实测人数。
- 任一项缺证据或口径不清都允许“待核实”。标签不默认成为硬筛条件。

正式规模标签位于 `shared/job-search-core/data/company-size-tags.json`。私有链路依据已核实的性质和公司简介事实生成、审核并发布，公开产品只读取结果。
